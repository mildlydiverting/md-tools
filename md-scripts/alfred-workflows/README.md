# alfred-workflows — copies of my own Alfred workflows

Reference copies of the Alfred workflows I made (not third-party ones), taken
2026-11-11 from the synced Alfred preferences in
`~/Library/CloudStorage/Dropbox/cross-machine-preferences/alfred/alfred preference sync/`.
The live versions are there; Dropbox syncs them between Macs.

Each folder holds a workflow's `info.plist`, which contains all of its logic
and scripts. Left out: `prefs.plist` (personal settings such as the Zoom link),
and any icon that was online-only in Dropbox when the copy was made.

To restore one: zip the folder's contents, rename the zip to
`Name.alfredworkflow`, and double-click it. Or use
`../../md-alfred-dezoomify/alfred-package-workflow.zsh <folder>`.
